# 영어 29번 어법 인쇄물

## 1. 파일

| 파일 | 대상 | 내용 |
| --- | --- | --- |
| out/영어29번_어법기출73제_문제지.pdf | 학생 | 기출 73문항 시험지, A4 2단, 한 단에 2문항 |
| out/영어29번_어법기출73제_교사용.pdf | 교사 | 같은 시험지에 정답 번호 원 표시와 문항별 정답, 고친 형태 |
| out/영어29번_어법기출73제_정답과해설.pdf | 교사 | 빠른 정답표, 문항별 출제 의도, 정답 풀이, 나머지 선지 한 줄 해설, 관련 개념 절 |
| out/영어29번_어법개념정리_학생용.pdf | 학생 | 개념 정리 교재, 판단 규칙과 풀이 순서의 빈칸, 확인 문제 정답 없음 |
| out/영어29번_어법개념정리_교사용.pdf | 교사 | 같은 교재에 빈칸 답을 빨간색으로 표시, 확인 문제 정답 부록 |

- 학생용과 교사용은 같은 원고로 조판해 줄바꿈이 같음. 교사용의 빨간 표시만 학생용에서 빠짐. 개념 정리 교사용은 확인 문제 정답 부록만큼 쪽이 더 많음
- 학생용 PDF에는 정답 텍스트가 들어 있지 않음 (pdftotext 검사)
- 시험지 문항 순서는 최근 시행 시험부터. 문항마다 [ ] 안에 출제 시험, 28번으로 출제된 문항은 원래 번호 표기
- 2026년 7월 학평과 2020년 4월 학평은 지문을 확보하지 못해 시험지에서 빠짐

## 2. 원고

| 파일 | 내용 |
| --- | --- |
| src/passages.json | 지문 전문. 밑줄형은 {n\|표현}, 네모형은 {A\|선택1\|선택2}, 각주, 발문, 복원 근거와 검증 결과 |
| src/총정리_빈칸.md | 개념 정리 원고. 빈칸은 {{답}}, 표시를 지우면 docs/03_어법총정리.md와 같음 |
| src/explanations.json | 해설지 원고. 문항별 정답 풀이(answer_text)와 나머지 선지 한 줄 해설(others) |
| style.py | 지면 치수, 글꼴, 쪽 배치 스크립트 |
| build_pdf.py | PDF 생성 |
| DESIGN.md | 디자인 조사와 명세 |

- 지문은 시험지 PDF 추출본, 공개 데이터셋, 학원 해설 원문을 대조해 복원하고 독립 검증함. 73개 중 4개는 원문 출처가 1곳뿐이라 확인 표시를 problem으로 둠 (passages.json의 verify, notes)
- 기출 지문의 저작권은 출제 기관과 원저작자에게 있음. 수업용 비영리 배포에만 사용

## 3. 다시 만들기

- 필요한 것은 Python 3, playwright(Chromium), markdown, pymupdf
- 글꼴은 은바탕, 은돋움, 은디나루, 은그래픽(GPL-2)과 Liberation Serif(OFL)
  - Ubuntu 패키지 fonts-unfonts-core, fonts-unfonts-extra, fonts-liberation의 TTF를 한 디렉터리에 모음
  - 머리말 템플릿이 시스템 글꼴을 쓰므로 같은 파일을 ~/.local/share/fonts에도 복사하고 fc-cache -f 실행
- 명령은 `python3 grammar29/print/build_pdf.py --fonts <글꼴 디렉터리>`
