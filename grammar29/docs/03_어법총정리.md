# 고3 영어 어법 총정리

## 1. 동사

### 1.1 주어와 동사의 수일치

#### 판단 규칙

- 동사의 수는 수식어구를 뺀 주어에 맞춤
  - 주어 뒤 전치사구, 관계절, 분사구, to부정사구, 동격절, 삽입절은 괄호로 묶음
  - 부분 표현(most, some, half, 분수) + of + 명사는 of 뒤 명사에 맞춤
- 단수 취급: 동명사구 주어, One of + 복수명사, every + 단수명사
- 복수 취급: A and B, the + 형용사(~한 사람들)
- 주격 관계대명사 뒤 동사는 선행사에 맞춤
  - 관계절 안에서 and, or로 이어진 동사도 같은 선행사에 맞춤
- 도치 구문과 there 구문은 동사 뒤 주어에 맞춤
- It is ~ that 강조 구문은 강조된 주어에 맞춤

### 1.2 동사 자리와 준동사 자리

#### 판단 규칙

- 한 문장의 동사 수 = 접속사 수 + 관계사 수 + 1
  - 생략된 관계대명사와 접속사 that도 셈
  - 콤마 사이 삽입절, so to say 같은 삽입 어구는 빼고 셈
- 문장에 동사가 없으면 밑줄은 동사 자리
  - 긴 주어 뒤, that절, 관계절, 의문사절, so that절 안의 동사 자리
  - 부사절(While, When) 뒤 주절 동사 자리, 주어가 없으면 명령문 동사원형
- 동사가 이미 있고 접속사가 없으면 밑줄은 준동사 자리
  - 명사 뒤 수식은 분사: 능동이면 현재분사, 수동이면 과거분사 (2.1)
  - 주어 자리는 동명사나 to부정사, 동사원형은 불가
- with + 명사 + 분사 (부대상황), with 뒤에 동사는 불가

### 1.3 능동태와 수동태

#### 판단 규칙

- 주어가 동작을 하면 능동태, 동작을 받으면 수동태(be+과거분사)
  - 관계절 동사는 선행사, 대명사는 가리키는 명사로 판단
- 타동사 뒤에 목적어가 없으면 수동태
  - 목적어가 관계사로 앞에 나간 경우는 능동 그대로 (the book that she is reading)
- happen, occur, appear, exist 같은 자동사는 수동태 불가
- 4형식 수동태는 뒤에 목적어가 남음 (Students are given hints.)
- 구동사 수동태는 전치사까지 유지 (A is referred to as B)
- 조동사, 완료와 결합: 조동사+be+과거분사, have been+과거분사

### 1.4 대동사

#### 판단 규칙

- 앞 동사가 일반동사면 do, does, did
- 앞 동사가 be동사나 수동태면 be동사
- 앞 동사에 조동사나 완료 have가 있으면 같은 조동사나 have
- 대동사의 수는 대동사의 주어에 맞춤
  - as, than, neither 뒤 도치면 대동사 뒤 명사가 주어
- 대동사의 시제는 그 절이 가리키는 시점에 맞춤

## 2. 준동사

### 2.1 현재분사와 과거분사

#### 판단 규칙

- 꾸밈을 받는 명사(또는 설명하는 주어, 목적어)가 동작을 하면 현재분사, 동작을 받으면 과거분사
- 타동사의 분사 뒤에 목적어가 있으면 현재분사, 없으면 과거분사
  - 4형식 동사의 과거분사는 뒤에 목적어 하나가 남음 (students given a chance)
  - 5형식 동사의 과거분사는 뒤에 보어만 남음 (judged equivalent)
- 자동사는 수동 불가, 명사를 꾸밀 때 현재분사 (a record beginning with childhood)
- 감정 동사(motivate, depress, humiliate, damage)의 분사
  - 감정을 일으키는 원인이면 현재분사
  - 감정을 느끼는 쪽이면 과거분사
- 지각동사 + 목적어 + 과거분사 (목적어가 동작을 받을 때)

## 3. 연결어

- 뒤가 완전한 절이면 관계부사(where, when)나 전치사+관계대명사
- 뒤가 불완전한 절이면 관계대명사 which

- where의 선행사는 장소 외에 상황, 사례를 뜻하는 추상명사도 가능

### 3.2 명사절 접속사 that, whether, if

#### 판단 규칙

- that, whether, if 뒤에는 완전한 절
- 확정된 내용이면 that, '~인지 아닌지'면 whether
- 추상명사 뒤 내용을 설명하는 동격절은 that
- if 불가, whether만 쓰는 자리
  - whether + to부정사, whether A or B (양보 부사절)
  - 전치사 뒤, 주어 자리, whether or not

#### 판단 규칙

- 관계대명사 뒤에는 불완전한 절
  - 주격은 주어가 빠진 절, 목적격은 목적어가 빠진 절
- 장소 선행사라도 뒤 절에 목적어가 빠지면 where가 아닌 관계대명사
- whose + 명사 뒤에는 완전한 절, 선행사와 명사는 소유 관계
  - whose 바로 뒤가 동사면 틀린 형태
- 콤마 뒤 계속적 용법에 that 불가
- 두 절 사이에 접속사가 없으면 대명사 it, them 대신 관계대명사 which
  - 수량사 + of + which (both of which)

### 3.4 what과 that의 구분

#### 판단 규칙

- what = 선행사를 포함한 관계대명사, 앞에 선행사가 없고 뒤가 불완전한 절
- 선행사 없음 + 불완전한 절 → what
- 선행사 없음 + 완전한 절 → 접속사 that
- 선행사 있음 + 불완전한 절 → 관계대명사 that, which
- 문장 맨 앞 What절은 주절 동사 앞까지 묶어 판단
- whatever + 명사, whatever절 뒤에 주절이 따로 있으면 양보 부사절

## 4. 품사와 대명사

### 4.1 형용사와 부사

#### 판단 규칙

- 보어와 명사 수식은 형용사, 동사, 형용사, 부사, 문장 수식은 부사
- 2형식 동사(be, become, remain) 뒤 주격보어는 형용사
- make, find, keep + 목적어 + 목적격보어(형용사)
  - 목적어가 길면 make + 형용사 + 목적어 (make possible the growth)
- 보어가 앞으로 나간 어순은 원래 어순으로 되돌려 판단
  - So + 보어 + be + 주어 → 주어 + be + so + 보어
  - as + 보어 + as + 주어 + be (양보) → though + 주어 + be + 보어
  - how + 보어 + 주어 + become → 주어 + become + 보어
  - the + 비교급 + 주어 + be → 주어 + be + 비교급
- wherever possible = wherever it is possible
- 보어가 이미 있으면 그 앞에서 꾸미는 말은 부사 (remains deeply problematic)
- 명사 + ly(friendly, costly, lively)는 형용사

#### 기출 예문

| --- | --- | --- | --- | --- |

### 4.2 재귀대명사

#### 판단 규칙

- 목적어가 주어와 같은 대상이면 재귀대명사, 다른 대상이면 인칭대명사
  - 비교 기준은 밑줄이 속한 절의 주어 (how절, as절 안이면 그 절의 주어)
- 준동사는 의미상 주어와 비교
  - allow, force, compel + 목적어 + to부정사는 앞 목적어
  - 주격 관계절은 선행사
- 동명사구가 주어면 목적어는 다른 대상이라 인칭대명사 (Knowing that ~ makes them feel good)

## 5. 특수 구문

### 5.1 병렬 구조

#### 판단 규칙

- and, but, or로 이어지는 말은 같은 문법 역할과 형태
- 병렬 짝은 바로 앞 단어가 아니라 밑줄과 같은 역할을 하는 말

### 5.2 가주어와 가목적어 it

#### 판단 규칙

- 긴 to부정사구, that절 주어는 뒤로 보내고 가주어 it
- find, make + it + 형용사 + (for 의미상 주어) + to부정사, it은 가목적어

### 6.2 예상 문제

다음 글의 밑줄 친 부분 중, 어법상 <u>틀린</u> 것은?

Scientists have long wondered whether animals feel regret. In one experiment, rats ①&nbsp;<u>offered</u> a choice between waiting for a favorite flavor and accepting a less desirable one right away sometimes made the wrong decision. When this happened, they paused and looked back at the option they had passed up, as if blaming ②&nbsp;<u>themselves</u> for the choice. So ③&nbsp;<u>consistent</u> was this reaction that it appeared in nearly all of the animals tested. In later trials, the rats waited longer for the better flavor than they ④&nbsp;<u>did</u> before. Researchers still cannot say ⑤&nbsp;<u>what</u> the rats actually experience regret or merely react to a lost reward, but the results suggest that the animals learn from their own mistakes.

- 정답 ⑤ what → whether
- 함정 뒤가 완전한 절이고 '~인지 아닌지' 뜻

#### 확인 문제

1. The final score was so [disappointed / disappointing] that the players left the field in silence.
2. Few people know [what / whether] the bridge will be repaired before winter.
3. Nobody expected how [popular / popularly] the small café would become.
4. The new rule was approved faster than the old one [did / was].
5. Children who constantly compare [them / themselves] with others often lose confidence.
